## Retrieval Notes

- Use the most specific document available when answering user questions.
- Never invent pricing, schedules, policies, or commercial details.
- If the requested information is unavailable or requires live confirmation, escalate to the admissions team.
- Follow the escalation rules defined in `04-escalation-triggers.md`.
