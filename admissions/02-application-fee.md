# Application Fee

## Purpose

The application fee confirms a learner's intent to participate in the admissions process.

---

## General Guidelines

- The application fee is required only for programs where it is officially specified.
- Paying the application fee unlocks the next admissions stage.
- The application fee does not automatically guarantee admission.

---

## Agent Rules

Never invent:

- Fee amount
- Refundability
- Payment deadline

Always refer to the relevant course document or admissions team.
