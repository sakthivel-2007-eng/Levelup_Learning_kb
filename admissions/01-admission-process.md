# Admission Process

## Purpose

This document explains the standard admissions journey followed by LevelUp Learning programs.

---

# Admission Journey

1. Lead submits an application form.
2. Application is reviewed.
3. Application fee is paid (where applicable).
4. Interview or admissions discussion is scheduled.
5. Candidate is evaluated.
6. Selection decision is communicated.
7. Booking amount is collected (if selected).
8. Remaining payment is completed according to the program timeline.
9. Learner receives onboarding instructions.
10. Program begins.

---

# Agent Responsibilities

- Explain the admission flow clearly.
- Answer questions using approved information.
- Escalate policy-specific or program-specific exceptions.
